
igdb
total_rating: A média combinada entre usuários e crítica.
total_rating_count: O total de todos os votos somados.

genres: IDs dos gêneros do jogo (RPG, Tiro, Aventura).
themes: IDs dos temas (Cyberpunk, Ficção Científica, Mundo Aberto).

videos: IDs que referenciam trailers e vídeos (geralmente links do YouTube).

platforms: IDs dos consoles e sistemas onde o jogo está disponível (PC, PS5, Xbox, etc).
game_modes: IDs dos modos de jogo (Single player, Multiplayer, Co-op).

language_supports: IDs que indicam quais idiomas o jogo suporta e se é áudio ou legenda.

franchises: ID da franquia à qual o jogo pertence (ex: franquia "Cyberpunk").
similar_games: IDs de outros jogos que o IGDB recomenda por serem parecidos com este.
external_games: IDs que conectam este registro a outras lojas (Steam ID, Epic Store ID, GOG ID).

rawg:
imagens(in game), rating, playtime

background_image: Uma URL para a imagem principal (geralmente uma concept art ou wallpaper) que serve de fundo para o jogo.
rating: A nota média dada pelos usuários do RAWG (normalmente de 0 a 5).
rating_top: A maior nota possível que um usuário pode dar (geralmente 5).
ratings: Um detalhamento de como os usuários votaram, dividido por categorias:
exceptional (Excepcional)
recommended (Recomendado)
meh (Médio)
skip (Pular/Ruim)
ratings_count: Total de usuários que deram uma nota numérica ao jogo.
added: Um número muito importante no RAWG; representa o total de pessoas que adicionaram este jogo às suas coleções na plataforma (indicador de popularidade).
Status da Comunidade (added_by_status)
Este objeto mostra o que os donos do jogo estão fazendo com ele:
yet: Querem jogar (na lista de desejos).
owned: Já possuem o jogo.
beaten: Já terminaram o jogo.
toplay: Está na lista para jogar em breve.
dropped: Começaram mas desistiram.
playing: Estão jogando no momento.

platforms: Lista de consoles/sistemas onde o jogo está disponível (PC, PS5, Xbox, etc).
genres: Categorias principais do jogo (Action, Shooter, RPG, etc).
stores: Lista de lojas digitais onde o jogo pode ser comprado (Steam, GOG, Epic, etc).
tags: Palavras-chave que descrevem o jogo em detalhes (ex: "Singleplayer", "Atmospheric", "Sci-fi"). Note que as tags vêm em diversos idiomas (inglês, russo, etc).
Outros Metadados
playtime: Tempo médio que os jogadores levam para completar o jogo (em horas).
